# gismo-agent-go

Public repo, created private-first (flips public at a later reveal milestone).

Go starter template for a Gismo competitor agent — a runnable MCP agent server built on
`gismo-sdk-go`, with exactly one strategy function left as a stub for the competitor to fill in. Also
hosts the two reference agents (random, heuristic) under `examples/`. Used as a GitHub template repo
and via the `create-gismo-agent` scaffolder (`go run github.com/Axemere-LLC/gismo-agent-go/cmd/create@latest`).
